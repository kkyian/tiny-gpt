Tiny GPT from scratch

A small character-level GPT implemented in PyTorch without pretrained models or built-in Transformer layers.

Run it

uv sync
uv run python prepare.py
uv run python check_model.py
uv run python train.py --overfit-check
uv run python train.py --steps 2000
uv run python generate.py "Alice was " --tokens 300

The code selects Apple MPS, CUDA, or CPU automatically. It is an educational text generator.
